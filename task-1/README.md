Talora – Internship Landing Page
A responsive landing page designed to introduce the Talora internship program. The website provides information about the program, its benefits, application stages, and contact sections.

Technologies Used
React.js
JavaScript
CSS3
Vite
React Icons

Installation and Setup
1. npm create vite@latest ./
2. npm run dev 
3. React Icons website -npm install i
https://react-icons.github.io/react-icons/search/#q=facebook

Features
Semantic HTML elements are used.
Navigation links and buttons are keyboard accessible.
Footer with navigation and social media links.
Hover effects and modern UI design.

Responsive Testing
The website is designed and tested for:
Mobile: 360px
Desktop: 1280px
